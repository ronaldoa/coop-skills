# Rebuilding or auditing the router (`AGENTS.md`)

The router is the one **reconstructible** layer: every section is derived from a named
source, so losing it costs rebuild time, not memory. The dashboard and `project-memory/`
cannot be regenerated by any recipe — which is why the router may be lossy and they may
not, and why the router must never hold truth that exists nowhere else.

## Section → source of truth

| Section | Derived from |
|---|---|
| Project overview | `README.md` |
| Session bootstrap | [bootstrap.md](bootstrap.md) reading order |
| Commands | build / test / run manifest |
| Architecture | the source tree, read structurally — `path#symbol` pointers, no inlined implementation |
| Repo map | workspace manifest + top-level layout |
| Key config | env template cross-checked against the code's defaults |
| Design specs (doc router) | a survey of `docs/` (below), or the generated `docs/INDEX.md` ([doc-index.md](doc-index.md)) |

Audit = re-derive one section from its source and diff.

## The doc-router survey

Run it in a read-only Explore subagent. Constraints for its prompt:

- read **at most the first 15 lines** of each doc (stamp, title, first paragraph) — this is
  routing, not summarizing;
- classify status from what is written; **never guess** — unknown is `undetermined`;
- one row per active doc: `<trigger> → <path> + STATUS`; superseded docs that could be
  mistaken for current get a row with an explicit marker;
- name the canonical doc where several cover one topic.

## Route, don't store

A router edit that adds any of these is misfiled — move it and leave a one-line route:

| Content | Home |
|---|---|
| spec content | `docs/` |
| status narrative in a row | update the label; narrative lives in the doc or dashboard |
| baselines, calibration numbers | `experiments.md` |
| rejected approaches | `decisions.md` |
| "do not change" invariants | `architecture.md` |
| blockers, next commands | dashboard / line `§0.0` |
| user preferences | personal memory |
| tool-specific behaviour | the tool overlay (`CLAUDE.md`), which references `AGENTS.md` |

Row contract: one route = one line; a status change updates the label, it never appends
narrative. The doc-budget gate enforces the line width ([enforcement.md](enforcement.md)).
